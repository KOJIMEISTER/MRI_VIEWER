# MRI_VIEWER

![Логотип](https://github.com/KOJIMEISTER/MRI_VIEWER/blob/main/imgs/logo.png)

**MRI_VIEWER** — мощное приложение для классификации и сегментации опухолей мозга по МРТ-снимкам. Используя современные нейронные сети, приложение позволяет не только определить тип опухоли, но и визуально выделить ее на изображении.

## Возможности

- **Классификация опухолей мозга**: Определение типа опухоли на основе МРТ-снимков.
- **Сегментация опухолей**: Визуальное выделение опухоли на изображении для лучшего понимания ее расположения и размеров.
- **Интуитивно понятный интерфейс**: Простота использования благодаря удобному графическому интерфейсу.
- **Поддержка различных последовательностей МРТ**: T1, T2, FLAIR.
- **Настраиваемые параметры пакетов изображений**: Возможность загрузки и управления пакетами МРТ-снимков.

## Технологии

- **Языки программирования**: C++, Python
- **Фреймворки и библиотеки**:
  - [Qt](https://www.qt.io/) для создания графического интерфейса.
  - [TensorFlow](https://www.tensorflow.org/) и [Keras](https://keras.io/) для разработки и использования нейронных сетей.
  - [Boost.Python](https://www.boost.org/doc/libs/1_82_0/libs/python/doc/html/index.html) для интеграции C++ и Python.
- **Инструменты**: CMake, Qt Creator

## Установка

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/KOJIMEISTER/mri_viewer.git
   ```

2. **Установите необходимые зависимости:**

   - **Qt**: [Скачайте и установите Qt](https://www.qt.io/download).
   - **Python**: Убедитесь, что у вас установлен Python 3.11 и необходимые библиотеки (`tensorflow`, `keras`, `opencv-python`).

   ```bash
   pip install tensorflow keras opencv-python
   ```

   - **Boost**: Скачайте и установите Boost, включая модуль `boost_python`.

3. **Сборка проекта:**

   Откройте проект в **Qt Creator** и соберите его. Убедитесь, что пути к Boost и Python правильно указаны в файле проекта `MRI_VIEW.pro`.

   ```bash
   cd mri_viewer
   qmake
   make
   ```

4. **Запуск приложения:**

   После успешной сборки запустите приложение из Qt Creator или из скомпилированной директории.

## Использование

1. **Загрузка пакета изображений:**

   В главном меню выберите `Файл -> Загрузить пакет`, укажите директорию с МРТ-снимками и настройте параметры пакета (последовательность и плоскость снимков).

2. **Классификация опухоли:**

   Перейдите в `Диагноз -> Составить диагноз`. Выберите необходимый пакет изображений и дождитесь завершения процесса классификации. Результаты будут отображены на экране.

3. **Сегментация опухоли:**

   Для выделения опухоли выберите `Обнаружение -> Выполнить выделение`. После завершения процесса вы увидите изображение с визуально выделенной опухолью.
